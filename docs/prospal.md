## 1. 项目背景

艾恩国际医疗（IM Medical International Consulting）是一家专注于跨境医疗咨询的机构，为患者提供从诊疗咨询到海外就医的一站式国际医疗服务，覆盖美国、日本、英国、德国、新加坡等国家和地区。

官网承担的核心职责：

1. **品牌展示** —— 建立「连接全球优质医疗资源」的专业形象；
2. **患者引流** —— 通过「寻找治疗方法」「疾病与治疗」「搜索」等工具型入口，将潜在患者引导至预约咨询表单；
3. **信息承载** —— 疾病、医生、医院、药物、案例、新闻、体检套餐等结构化信息的检索与浏览；
4. **线索转化** —— 全站复用的「免费获取全球就医评估方案」咨询表单，收集姓名 / 电话 / 病情简述。

## 4. 核心流程与交互

### 4.1 主流程：寻找治疗方案 → 咨询转化

```
用户进入
  │
  ├─ 首页 / 疾病与治疗 / 寻找治疗方法 / 搜索
  │        │（输入疾病关键词 / 点击热门标签）
  │        ▼
  │     列表页（疾病与治疗 / 治疗药物 / 全球医生 / 合作医院）
  │        │（筛选：国家 / 类别 / 年龄）
  │        ▼
  │     详情页（药物详情 / 医生详情 / 医院详情 / 体检详情）
  │        │（查看医院/医生/套餐 + 联系）
  │        ▼
  └─ 咨询表单（全站 consult-banner）
          姓名 + 联系电话 + 病情简述 → 立即提交
```

### 4.3 核心数据统计（品牌页）

设计稿中反复出现的品牌背书数据，应作为站点级常量维护：

- **远程问诊**：67% 远程第二意见后治疗方案改变（斯坦福研究）；20% 癌症患者第二意见后诊断或治疗方案不同（MD安德森）；54% 第二意见推荐治疗调整（美国临床肿瘤学会）
- **多学科远程咨询**：覆盖全球 TOP50 医院 / 200 位国际权威专家 / 72h 快速响应 / 67% 改变诊疗方案
- **企业家健康管理**：80% 企业家患高血脂等慢性病；60% 存在睡眠障碍；40% 每年未完成全面体检
- **日本体检案例**：182 人赴日本体检，5% 查出肿瘤（最小 1mm，类癌阶段）
